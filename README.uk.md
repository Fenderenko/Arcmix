# Arcmix

**Українська** · [English](README.md)

Невелика програма для Windows, що живе в треї: баланс гра / чат для будь-яких програм, еквалайзер,
обробка мікрофона й налаштування гарнітури в одному вікні біля годинника.

Arcmix виріс з ідеї проєкту [OpenChatMix](https://github.com/Swiftlyx/OpenChatMix) від Swiftlyx; цей репозиторій — його форк.

## Можливості

- **Баланс гра / чат для будь-яких програм.** Програми розкладаються по групах Гра / Чат / Медіа: перетягніть програму на групу або додайте кнопкою «+»; кнопка з кошиком прибирає програму («+» повертає). Кожна програма має власну гучність, а баланс (коліщатко на гарнітурі, повзунок у вікні чи гарячі клавіші) множить ці рівні, а не затирає їх.
- **Автоприглушення.** Поки в програмі «Чату» хтось говорить, гра (і за бажанням «Медіа») стихає. Програми чату слухаються напряму, тож музика чи відео його не вмикають.
- **Пам'ять гучності.** Гучність програм і мікрофона повертається, якщо її скине Windows чи інша програма.
- **Еквалайзер для всього звуку на будь-якому пристрої.** «EQ Windows» — одна крива на все, що грає на пристрої виводу, — колонки, USB- чи Bluetooth-навушники — без кабелів і без затримки, через власний модуль Arcmix у звуковому рушії Windows. Ефекти самого пристрою (Windows, Realtek, Dolby…) працюють і далі: модуль запускає їх усередині себе. Див. [Модуль Arcmix](#модуль-arcmix).
- **Пресети еквалайзера.** Вбудовані пресети, свої пресети (змінити, зберегти, перейменувати, видалити) і власний еквалайзер гарнітури з пресетами, вбудованими в неї, де вони є. Якщо встановлено [Equalizer APO](https://sourceforge.net/projects/equalizerapo/), Arcmix керує й ним і додає корекцію AutoEQ для вашої моделі навушників.
- **Мікрофон.** Гучність, вимкнення клавішами, «натисни, щоб говорити» клавішею чи кнопкою миші, м'які звукові сигнали й позначка на значку в треї.
- **Послухати себе.** Запис на 5 секунд і відтворення або мікрофон у навушниках наживо — уже після обробки.
- **Обробка мікрофона.** Нейромережевий шумодав — легкий RNNoise або шумодав NVIDIA на відеокартах RTX (якщо встановлено NVIDIA Audio Effects SDK), що прибирає й луну кімнати, з регульованою силою, — компресор, поріг шуму, межа гучності й 64-бітні VST2 / VST3-плагіни в порядку, який можна змінити. Потрібен віртуальний аудіокабель, наприклад безкоштовний [VB-CABLE](https://vb-audio.com/Cable/).
- **Заряд Bluetooth-навушників** у шапці — такий, як його знає Windows.
- **Налаштування гарнітури.** Заряд із попередженнями й прогнозом часу, чутність власного голосу, автовимкнення, індикатор вимкненого мікрофона тощо — залежно від моделі.
- **Пристрої виводу за пріоритетом.** Звук іде на найвищий під'єднаний пристрій вашого списку: гарнітуру ввімкнули — на неї, вимкнули — на наступний. За бажанням перемикається й мікрофон гарнітури. Що робити, коли пристрій під'єднали (перемкнути на нього, якщо він вищий у списку, завжди чи ніколи) і коли від'єднали, — вирішуєте ви.
- **Маршрутизація звуку** *(експериментально)*. Гра, чат і медіа — в окремі віртуальні кабелі: для стріму чи окремого еквалайзера на кожну групу.
- **Один перемикач віртуальних кабелів.** Налаштування → Пристрої → «Віртуальні кабелі» вимикає маршрутизацію й оброблений мікрофон разом: звук і мікрофон ідуть напряму, налаштування лишаються.
- **Підказка на екрані.** Зміна балансу чи перемикання пристрою виводу або вводу гарячими клавішами показує невелику підказку на екрані.
- **Іконка в треї.** Знак програми, поки баланс порівну; дві капсули кольорами гри й чату з теми, щойно він зміниться, — або заряд гарнітури замість знака. Коліщатко миші над іконкою змінює баланс або показує заряд.
- **Компактне вікно.** Чотири вкладки — Мікс, Звук, Мікрофон, Налаштування; налаштування відкриваються сторінками, а бічні кнопки миші «назад» / «вперед» гортають вкладки й сторінки.
- **Функції, які можна вимкнути.** Налаштування → Загальне → Функції: вимкнена функція зникає з вікна й не працює.
- **Перевірка оновлень.** Налаштування → Про програму → *Перевірити оновлення* питає GitHub про останній випуск. Сама програма нічого не перевіряє.
- **Теми («Чорна діра» за замовчуванням або власні кольори), профілі, гарячі клавіші, налаштування у файлі, 9 мов** (українська, English, Deutsch, Français, Español, Português (Brasil), Polski, Italiano, Türkçe).

## Завантаження й встановлення

1. Завантажте `Arcmix-1.2.0.zip` з [Releases](../../releases) і розпакуйте в будь-яку теку (наприклад, `C:\Programs\Arcmix`).
2. Запустіть `Arcmix.exe`. Файл не має цифрового підпису, тож Windows SmartScreen може попередити: натисніть **Докладніше → Усе одно запустити**.
3. З'явиться значок у треї (клік — відкрити вікно). Коротке знайомство при першому запуску допоможе з основним, зокрема з модулем еквалайзера.

Потрібно: Windows 10 або 11, 64-бітна, з Microsoft Edge WebView2 Runtime (у Windows 11 він уже є; у Windows 10
приходить разом з Edge або його можна взяти в [Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/)).

Налаштування, журнал і звіти про аварії лежать у `%APPDATA%\Arcmix`. **Налаштування → Загальне → Запускати разом
з Windows** додає програму в автозапуск (ключ `Run` поточного користувача).

**Видалення:** вимкніть *Запускати разом з Windows*, вийдіть через меню значка в треї, видаліть теку з `Arcmix.exe`
і, якщо налаштування більше не потрібні, `%APPDATA%\Arcmix`.

## Як почати

**Баланс.** Відкрийте вікно й розкладіть програми по групах: гру — в «Гру», Discord — у «Чат», браузер чи плеєр —
у «Медіа». Перетягніть програму на вкладку групи або натисніть «+» біля «Програми» й оберіть одну з відкритих програм.
Потім крутіть коліщатко на гарнітурі чи повзунок. Гарячі клавіші за замовчуванням: `Ctrl+Shift+→` більше гри,
`Ctrl+Shift+←` більше чату, `Ctrl+Shift+↓` баланс порівну, `Ctrl+Alt+M` вимкнути мікрофон, `Ctrl+Alt+→` / `Ctrl+Alt+←`
наступний / попередній пристрій виводу, `Ctrl+Alt+↓` / `Ctrl+Alt+↑` наступний / попередній пристрій вводу. Їх можна змінити в
**Налаштування → Гарячі клавіші** (клікніть дію й натисніть нове поєднання).

**Еквалайзер.** **Звук → Еквалайзер**: оберіть пресет або потягніть криву. Змінену криву можна зберегти як новий
пресет; свої пресети можна перезаписати, перейменувати й видалити. «EQ» з назвою гарнітури — власний еквалайзер
гарнітури; «EQ Windows» — одна крива на все, що грає на пристрої виводу: натисніть **Встановити** біля «Модуль Arcmix»
(раз на кожен пристрій). На гарнітурі з власним еквалайзером увімкніть «EQ Windows на гарнітурі», щоб діяли обидві криві.

**Обробка мікрофона** (шумодав, поріг, VST):
1. Встановіть [VB-CABLE](https://vb-audio.com/Cable/) і перезапустіть комп'ютер.
2. **Мікрофон → Обробка мікрофона**: увімкніть «Обробляти мікрофон», оберіть свій справжній мікрофон і *Передавати в: CABLE Input*.
3. Поки обробка ввімкнена, Arcmix ставить **CABLE Output** мікрофоном Windows за замовчуванням: Discord, гра й OBS
   з мікрофоном за замовчуванням чують оброблений голос (програмі, де вибрано конкретний мікрофон, треба вибрати
   **CABLE Output**). Вибір мікрофона в Arcmix тоді міняє лише те, що обробляється; вимкнули обробку — Windows
   отримує цей мікрофон назад. Перевірити голос можна в **Послухати себе**. Кабель додає близько 45 мс затримки, шумодав — ще близько 10 мс.
   «Порядок обробки» в кінці ланцюжка змінює порядок кроків.

**Маршрутизація звуку** *(експериментально)*: спрямовує Гру, Чат і Медіа в окремі віртуальні кабелі, наприклад щоб
записувати їх в OBS окремо. Кожній групі потрібен вільний кабель. Кабель обробки мікрофона маршрутизація не бере,
тож одного VB-CABLE на обидві функції не вистачить: ще кабелі дає
[VB-CABLE A+B](https://shop.vb-audio.com/en/audio-apps/12-vb-cable-ab.html) (donationware від VB-Audio; вкладати його в
інші програми не дозволено, тож беріть у їхньому магазині).

**Пристрої виводу за пріоритетом.** **Налаштування → Пристрої → Пріоритет пристроїв виводу → Змінити**: перетягніть
пристрої у свій порядок. Коли ввімкнено *Перемикати звук автоматично*, вивід Windows іде за найвищим під'єднаним;
«Під’єднали пристрій» і «Від’єднали пристрій» задають, що робити тоді.

## Модуль Arcmix

Еквалайзер «Весь звук» працює як ефект у звуковому рушії Windows, тож йому не потрібні віртуальні кабелі й він не
додає затримки. Ставиться окремо на кожен пристрій виводу: **Звук → Еквалайзер → EQ Windows → Встановити** (або під
час знайомства при першому запуску).

- **Windows попросить дозволу адміністратора**, а звук на секунду зникне, поки перезапускаються звукові служби.
- **Що змінюється:** модуль копіюється в `C:\Program Files\Arcmix\ArcmixApo.dll`, реєструється як звуковий ефект і
  додається до ефектів пристрою. Ефекти, які вже були в пристрою, працюють усередині модуля. Модуль не має цифрового
  підпису, тож Arcmix ще й ставить `DisableProtectedAudioDG = 1` (тоді звуковий рушій вантажить непідписані ефекти —
  так само робить Equalizer APO).
- **Прибрати** повертає ефекти пристрою як були, а захист — щойно модуля не лишиться на жодному пристрої.
- **Потрібно**, щоб для пристрою в Windows були ввімкнені «Покращення звуку»; вікно скаже, якщо їх вимкнено.
- **Не діє** на програми в монопольному режимі чи з ASIO та на Bluetooth-гарнітуру в режимі Hands-Free.

## Гарнітури

Баланс, автоприглушення, пресети еквалайзера, мікрофон, маршрутизація й теми працюють з будь-якою гарнітурою.
Заряд, чутність власного голосу, апаратний еквалайзер та інші налаштування гарнітури потребують протоколу самої гарнітури:

- **Arctis 7+, 7P+, 7X+** мають власний драйвер і перевірені на справжній гарнітурі.
- Інші моделі Arctis (Arctis 1, 5, 7, 9, Pro, Nova 3 / 4 / 5 / 7 / Pro / Elite, GameBuds та інші) — з описів пристроїв
  [Linux-Arctis-Manager](https://github.com/elegos/Linux-Arctis-Manager) у `web/devices.json`. Їх **не перевірено**:
  частини налаштувань може не бути або вони поводитимуться інакше. Звіти вітаються.
- **Nova 7 Gen 2, Nova 5, GameBuds, Nova Elite:** їхній параметричний апаратний еквалайзер підготовлено, але вимкнено,
  доки хтось не перевірить його на справжній гарнітурі. Щоб випробувати, закрийте Arcmix, додайте `"untestedEq": true`
  у `%APPDATA%\Arcmix\config.json` і запустіть знову; розкажіть, як вийшло.
- Без підтримуваної гарнітури вікно нічого не показує про гарнітуру (ні заряду, ні sidetone, ні еквалайзера гарнітури);
  усе інше працює.

## Відомі обмеження

- **Окремий еквалайзер для гри / чату / медіа** можливий лише через маршрутизацію у віртуальні кабелі: Windows захоплює
  звук програми вже після її гучності, тож заглушити оригінал і грати оброблену копію не можна.
- **Bluetooth-гарнітури:** коли програма відкриває мікрофон гарнітури, Windows перемикає її в режим Hands-Free (моно,
  гірша якість). Так працює Bluetooth у Windows, це не налаштування Arcmix.
- **Програми виробника гарнітури**, що створюють свої віртуальні пристрої чи змінюють гучність програм, можуть
  конфліктувати з Arcmix. Закрийте їх або вимкніть у них мікшер.
- **Бездротові гарнітури після перезавантаження:** приймач може показувати гарнітуру вимкненою, доки її не вимкнути
  й не ввімкнути знову (так буває з Arctis 7+).
- **Модуль Arcmix** не дає окремої кривої на кожну програму: він діє на весь пристрій виводу.
- **Ще не перевірено наживо:** маршрутизацію звуку, «натисни, щоб говорити» й звукові сигнали мікрофона, кнопку на
  панелі завдань, вимкнення пристрою Windows зі списку, гарнітури поза родиною Arctis 7+.
- VST-плагіни мають бути 64-бітними.

## Якщо щось не так

**Налаштування → Налаштування й допомога → Звіт для діагностики** кладе на робочий стіл архів із журналом, звітом про аварію й
налаштуваннями. Додайте його, коли відкриватимете [issue](../../issues).

## Збірка з коду

Потрібні Windows і [Rust](https://rustup.rs/) з набором MSVC. Версії бібліотек зафіксовано в `rust/Cargo.lock`.

```sh
cd rust/apo
cargo build --release
cd ..
cargo build --release
```

Спершу збирається модуль звукового рушія (`rust/apo`): програма вшиває його в себе. Програма — `rust/target/release/arcmix.exe`; значок (`assets/app.ico`) і версію з `Cargo.toml` вшиває `build.rs`.
Тести: `cargo test --release`.

Інструменти в `tools/` потребують Python 3:

- `mkicon.py` — значок програми, знак на темній плитці (`assets/app.ico`, `assets/app.png`); `--svg` друкує векторний
  значок із зорями для «Про програму».
- `i18n_src.py` — джерело перекладів, генерує `web/i18n.json`; `check_i18n.py` показує, чого бракує.
- `gen_devices.py` — `web/devices.json` з тек `device-configs` Linux-Arctis-Manager.
- `rnnoise_model.py` — `assets/rnnoise.bin` з коду RNNoise.
- `mock/srv.py` — те саме вікно з вигаданими даними на http://127.0.0.1:8772/, щоб працювати над інтерфейсом без програми.
